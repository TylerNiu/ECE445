# ECE 445 — Team 23

Digital lab notebook and project documentation for Team 23.

## Repository structure

- `notebook/entries/` — chronological, dated lab-notebook entries
- `notebook/meetings/` — meeting notes and action items
- `proposal/` — project proposal drafts and supporting design material
- `design/` — block diagrams, subsystem documentation, calculations, and simulations
- `testing/` — test plans, procedures, raw results, and analysis
- `administrative/` — team planning, safety training records, and project schedule
- `references/` — papers, datasheets, standards, and other sources
- `media/` — photos, screenshots, and other supporting media

## Notebook workflow

1. Create a new file in `notebook/entries/` using the format `YYYY-MM-DD-short-description.md`.
2. Record the objective, work performed, measurements or observations, decisions, problems, and next steps.
3. Link relevant files, photos, calculations, and test results from the entry.
4. Do not rewrite old entries. If something changes, add a dated correction or follow-up entry.

See [`notebook/README.md`](notebook/README.md) and [`notebook/entries/TEMPLATE.md`](notebook/entries/TEMPLATE.md) for details.
